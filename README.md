# FZ Say — Global Exchange Rates

> Real-time currency exchange rates. No ads. No registration. ECB data.

**Live:** https://xzskainet.github.io/fz-say

---

FZ Say is a free currency exchange dashboard with rates for 30+ currencies updated daily by the European Central Bank.

## What you can do

- Check live exchange rates and 7-day trends for any currency
- See which currencies gained and lost the most today
- Convert between any two currencies instantly
- Compare two currencies side by side over 7D, 1M, 3M or 1Y
- Filter currencies by region — Americas, Europe, Asia, Oceania, Africa
- Estimate freelance income variance over time
- Plan a trip budget for up to 3 destinations

## Data source

Rates from the [European Central Bank](https://www.ecb.europa.eu) via [Frankfurter API](https://www.frankfurter.dev). Updated once per day around 16:00 CET. All values are indicative.

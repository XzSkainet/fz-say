# FZ Say — Global Exchange Rates

> Real-time currency exchange rates. No ads. No registration. ECB data + LatAm coverage.

**Live:** https://xzskainet.github.io/fz-say

---

FZ Say is a free currency exchange dashboard with rates for 38 currencies updated daily. Major currencies from the European Central Bank, plus Latin American currencies (ARS, CLP, COP, PEN, UYU, BOB) via an open secondary source.

## What you can do

- Check live exchange rates and 7-day trends for any currency
- See which currencies gained and lost the most today (Top Movers)
- See where each rate sits within its weekly high/low range
- Convert between any two currencies instantly
- Compare two currencies side by side over 7D, 1M, 3M or 1Y
- Explore an interactive world map colored by daily change
- Filter currencies by region — Americas, Europe, Asia, Oceania, Africa
- Estimate freelance income variance over time
- Plan a trip budget for up to 3 destinations

## Data sources

- **ECB currencies (32):** [European Central Bank](https://www.ecb.europa.eu) via [Frankfurter API](https://www.frankfurter.dev). Updated once per day around 16:00 CET.
- **LatAm currencies (6):** ARS, CLP, COP, PEN, UYU, BOB via [currency-api](https://github.com/fawazahmed0/exchange-api). Updated daily, 7-day history.

All values are indicative.
